# EditFlow Studio

Create a video editor where we can split, drag cut, merge videos, multiple timelines, blur specific area, add text at any point, mute video, and can export them in any format and in any frame with preview.
Create this in React JS with Bootstrap, No tailwind. 
It should be professional. A Basic Video editor with elegant look and sleek design and all basic features should be there and it should be working...

Create in React Js  with Bootstrap. only front now.
